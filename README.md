# Ember & Crust — High-Fidelity Pizza Landing Page Kit

## Included Files
- `index.html` — Full responsive landing page with sticky navigation, split hero banner, filterable menu cards, interactive pizza builder, and slide-over cart drawer.
- `styles.css` — High-contrast appetizing dark-charcoal, ember-red, and melted-cheese-gold theme.
- `script.js` — Interactive size pricing, category filtering, custom topping builder, and live cart calculation.
- `design-tokens.json` — Color tokens and asset manifest ready for Figma.
- `assets/*.png` — Transparent PNG overhead pizza illustrations (`hero-pizza.png`, `pizza-pepperoni.png`, `pizza-margherita.png`, `pizza-bbq.png`, `pizza-veggie.png`).

## How to Use
1. Unzip the archive and open `index.html` directly in any web browser.
2. To edit in Figma, import `index.html` via the **html.to.design** plugin or load the hex tokens from `design-tokens.json`.
